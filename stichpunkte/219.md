## Kernaussagen

- jMolecules drückt die Building Blocks des taktischen Domain-driven Design im Java-Code aus, als Annotationen oder als Interfaces.
- Ein Ausgangspunkt war Spring Data: Ein Repository macht die verwaltete Entität implizit zum Aggregate Root. jMolecules macht das explizit.
- Die Geschäftslogik hängt dann von einer dünnen Bibliothek ab, aber nicht von einer Ablaufumgebung wie Spring. Für Oliver ist das eine Abwägung: Man bekommt auch etwas dafür.
- Einige Regeln prüft der Java-Compiler über die Interfaces, weitere der APT als Compiler-Fehler. Alternativ gibt es die Regeln für ArchUnit und jQAssistant.
- Eine der Regeln: Ein Aggregate referenziert ein anderes nie als volles Objekt, sondern über die ID.
- Für bestehende Codebasen sind ArchUnit oder jQAssistant vielleicht besser geeignet, weil man sich den Regeln Schritt für Schritt nähern kann.
- Findet man Klassen über ihre Stereotypen, müssen Pakete nicht mehr nach Controllern, Services und Repositories gebildet werden und können fachliche Module kapseln.
- Value Objects wie eine E-Mail-Adresse lassen nur gültige Werte zu. Die Integrationen für Jackson und Spring übernehmen die Umwandlung an den Rändern der Anwendung.
- Ein großer Teil der JPA-Mappings lässt sich aus der Struktur eines Aggregates ableiten und beim Build generieren. Das geht auch für MongoDB und Spring Data JDBC.
- Alle Integrationen sind optional. Man kann auch nur die Typen benutzen.
- Spring Modulith kann aus diesen Konzepten eine Dokumentation der Module erzeugen.

## Glossar

- **jMolecules**: Java-Bibliothek, mit der man DDD-Konzepte im Code auszeichnet; Teil des Dachprojekts xMolecules
- **Aggregate Root**: Konzept aus dem DDD; hat eine ID und verwaltet per Definition den Lebenszyklus der zugehörigen Entitäten
- **Value Object**: Typ für einen fachlichen Wert, z.B. eine E-Mail-Adresse
- **APT**: Annotation Processing Toolkit, mit dem sich beim Kompilieren Code prüfen oder erzeugen lässt
- **ArchUnit**: Werkzeug, das Architekturregeln als Tests ausführt
- **jQAssistant**: Werkzeug, mit dem sich Regeln auf Code anwenden lassen
- **ByteBuddy**: Werkzeug zur Bytecode-Generierung, mit dem jMolecules beim Build Mappings ergänzt
- **Spring Modulith**: Spring-Projekt, in dem logische Module im Mittelpunkt stehen
- **Application Module Canvas**: generierte Übersicht über die nach außen sichtbaren Teile eines Moduls
