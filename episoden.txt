{%- comment -%}
  Template for /episoden.txt, the overview of all episodes that the "Let's talk it over"
  button on the home page hands to an LLM. Jekyll renders it on every site build, so the
  list is always in step with the repository. Nothing here is generated by a script.

  Where the data comes from:
  - one entry per post in _posts that has a title, newest first
    (date, title, episode_id, tags, URL)
  - _data/profile/<id>.yml: topics, guests, an optional note and the content profile
  - transcriptions/<id>.txt: if the file exists, the entry says "Transkript: ja" and
    links to it
  - the text of an entry is the profile; without a profile the summary in
    zusammenfassung/<id>.md; without that the first paragraph of the post or its
    description, whichever is longer. Summary and post text are cut to whole
    sentences of about max_words words.

  Adding a profile for a new episode: create _data/profile/<id>.yml, where <id> is the
  episode_id of the post. No other file needs to change.

    themen:            # optional, list of topics
    - Topic one
    gaeste:            # optional, list of guests
    - Guest Name
    hinweis: ...       # optional, one line printed above the transcript line
    sprache: de        # optional, de or en; default is the post's tag "English"
    profil: >-         # the content profile, plain text in one paragraph
      Text ...

# Software-Architektur im Stream: alle Folgen

Software-Architektur im Stream ist ein wöchentlicher Live-Stream mit Eberhard Wolff, Lisa
Schäfer, Ralf D. Müller und Lucas Dohmen, oft mit Gästen, seit 2020. Diese Datei listet alle
Folgen, die neuesten zuerst. Startseite: {{ site.url }}

> **Hinweis für das LLM:** Die Leserin oder der Leser sucht Folgen zu einem Thema oder einer
> Frage. Frag nach, wenn das Anliegen unklar ist. Such dann in dieser Datei nach dem Inhalt der
> Folgen, nicht nur nach Wörtern im Titel, und nenn mehrere passende Folgen, jeweils mit einem
> Satz, warum sie passt, und dem Link auf die Folgenseite. Bevorzuge bei zeitkritischen Themen
> wie KI-Werkzeugen, Cloud-Angeboten oder Regulierung die neueren Folgen und sag dazu, von wann
> eine Folge ist.
>
> Steht bei einer Folge „Transkript: ja“, kannst du die verlinkte Textdatei nachladen, um die
> Folge genauer zu beschreiben; sie enthält Zusammenfassung und Transkript. Kannst du nicht
> nachladen, gib den Link weiter: Auf der Folgenseite gibt es einen eigenen Knopf, um die Folge
> mit einer KI zu besprechen. Steht dort „Transkript: nein“, beschreibt die Inhaltsangabe nur,
> was vor der Sendung angekündigt war, nicht, was tatsächlich besprochen wurde. Sag das dazu,
> wenn du eine solche Folge empfiehlst.
>
> Stütze dich auf diese Datei und erfinde nichts über eine Folge, was hier oder im nachgeladenen
> Text nicht steht. Die Inhaltsangaben wurden mit KI erstellt und können Fehler enthalten;
> maßgeblich ist das Video. Englische Folgen sind auf Deutsch beschrieben; antworte in der
> Sprache der Leserin oder des Lesers. Findest du keine passende Folge, sag das.

      {%- assign expected = "/zusammenfassung/" | append: f.name -%}

{{- nl -}}
{%- for post in site.posts -%}
  {%- unless post.title -%}{%- continue -%}{%- endunless -%}
  {%- assign id = post.episode_id | append: "" -%}
  {%- assign key = "|" | append: id | append: "|" -%}
  {%- assign profile = site.data.profile[id] -%}
  {%- assign title = post.title | append: "" | strip -%}

  {%- assign language = "Deutsch" -%}
  {%- if post.tags contains "English" -%}{%- assign language = "Englisch" -%}{%- endif -%}
  {%- if profile.sprache == "de" -%}{%- assign language = "Deutsch" -%}
  {%- elsif profile.sprache == "en" -%}{%- assign language = "Englisch" -%}
  {%- elsif profile.sprache -%}{%- assign language = profile.sprache -%}
  {%- endif -%}

  {%- comment -%} content: profile, else summary, else announcement or description {%- endcomment -%}
  {%- assign html = "" -%}
  {%- assign content = "" -%}
  {%- assign source = "" -%}
  {%- assign profil = profile.profil | append: "" | strip -%}
  {%- if profil != "" -%}
    {%- assign content = profil -%}
    {%- assign source = "profil" -%}
  {%- elsif id != "" and summaries contains key -%}
    {%- assign file = "zusammenfassung/" | append: id | append: ".md" -%}
    {%- capture raw -%}{%- include_relative {{ file }} -%}{%- endcapture -%}
    {%- assign html = raw | markdownify -%}
    {%- assign mode = "all" -%}
    {%- assign source = "zusammenfassung" -%}
  {%- else -%}
    {%- assign html = post.content -%}
    {%- assign mode = "first" -%}
  {%- endif -%}

  {%- if source != "profil" -%}
    {%- comment -%} html to plain text without headings {%- endcomment -%}
    {%- assign text = "" -%}
    {%- assign chunks = html | split: "<h" -%}
    {%- for chunk in chunks -%}
      {%- assign first_char = chunk | slice: 0 -%}
      {%- if forloop.first -%}
        {%- assign part = chunk -%}
      {%- elsif "123456" contains first_char -%}
        {%- assign tail = chunk | split: "</h" | last -%}
        {%- assign part = tail | slice: 2, tail.size -%}
      {%- else -%}
        {%- assign part = "<h" | append: chunk -%}
      {%- endif -%}
      {%- assign t = part | strip_html | replace: "&nbsp;", " " | replace: "&lt;", "<" | replace: "&gt;", ">" | replace: "&quot;", '"' | replace: "&#39;", "'" | replace: "&amp;", "&" | remove: "*" | remove: "_" | remove: "`" | split: " " | join: " " -%}
      {%- if t != "" -%}
        {%- if mode == "first" -%}
          {%- assign text = t -%}
          {%- break -%}
        {%- endif -%}
        {%- assign text = text | append: " " | append: t -%}
      {%- endif -%}
    {%- endfor -%}
    {%- assign text = text | strip -%}

    {%- if source == "" -%}
      {%- assign description = post.description | append: "" | strip_html | remove: "*" | remove: "_" | remove: "`" | split: " " | join: " " -%}
      {%- assign text_words = text | split: " " | size -%}
      {%- assign description_words = description | split: " " | size -%}
      {%- if text_words > description_words -%}
        {%- assign source = "beitragstext" -%}
      {%- else -%}
        {%- assign source = "beschreibung" -%}
        {%- assign text = description -%}
      {%- endif -%}
    {%- endif -%}

    {%- comment -%} whole sentences up to about max_words words {%- endcomment -%}
    {%- assign sentences = text | replace: ". ", ".¦" | replace: "! ", "!¦" | replace: "? ", "?¦" | replace: "… ", "…¦" | split: "¦" -%}
    {%- assign count = 0 -%}
    {%- for sentence in sentences -%}
      {%- assign words = sentence | split: " " | size -%}
      {%- assign total = count | plus: words -%}
      {%- unless forloop.first -%}
        {%- if total > max_words -%}{%- break -%}{%- endif -%}
        {%- assign content = content | append: " " -%}
      {%- endunless -%}
      {%- assign content = content | append: sentence -%}
      {%- assign count = total -%}
    {%- endfor -%}
  {%- endif -%}

  {{- nl -}}
  {%- if id != "" -%}## Folge {{ id }}: {{ title }}{%- else -%}## Sonderfolge: {{ title }}{%- endif -%}
  {{- nl -}}{{- nl -}}
  Datum: {{ post.date | date: "%Y-%m-%d" }} · Sprache: {{ language }}
  {%- if profile.gaeste.size > 0 %} · Gäste: {{ profile.gaeste | join: ", " }}{%- endif -%}
  {{- nl -}}
  Seite: {{ site.url }}{{ post.url }}
  {{- nl -}}
  {%- if profile.themen.size > 0 -%}Themen: {{ profile.themen | join: ", " }}{{- nl -}}{%- endif -%}
  {%- if profile.hinweis -%}{{ profile.hinweis }}{{- nl -}}{%- endif -%}
  {%- if id != "" and transcripts contains key -%}
    Transkript: ja – Text: {{ site.url }}/transcriptions/{{ id }}.txt
  {%- elsif source == "beschreibung" -%}
    Transkript: nein – Inhaltsangabe aus der Kurzbeschreibung vor der Sendung
  {%- else -%}
    Transkript: nein – Inhaltsangabe aus der Ankündigung vor der Sendung
  {%- endif -%}
  {{- nl -}}
  {%- if content != "" -%}{{- nl -}}{{ content }}{{- nl -}}{%- endif -%}
{%- endfor -%}
