Eine wichtige Eigenschaft von Software ist die Sicherheit - schließlich werden immer mehr kritische Funktionen durch Software umgesetzt. LLMs bergen völlig neue Sicherheitsherausforderungen. Anders als klassische Systeme agieren sie probabilistisch. Gleichzeitig nutzen immer mehr Systeme LLMs. Auf dem iSAQB Software Architecture Forum sprach Sönke Magnussen mit Eberhard darüber, welche Strategien für eine bessere Sicherheit von LLM-Systemen nützlich ist.
