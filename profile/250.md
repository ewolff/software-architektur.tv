Live-Demo: Ralf D. Müller zeigt Lisa Schäfer, was ein agentischer Workflow ist und wie ein LLM seine eigene Arbeit überprüft. Leitfrage: Wie bringt man ein Modell dazu, Aufgaben eigenständig und verlässlich zu lösen? Am Beispiel Quadratwurzel zeigt er, dass Function Calling Halluzinationen eindämmt, weil das Modell rechnet statt rät. Sein eigenes Chat-Frontend arbeitet im Docker-Container mit Bash, Python, Browser, Diagrammerzeugung über Kroki und einem „inneren Dialog“, in dem das Modell sich selbst als Security- oder Wartbarkeitsexperten befragt. Lisa hakt kritisch nach: Woher weiß ich, dass mich das Modell nicht veräppelt? Eine absichtlich unterbestimmte Sortieraufgabe zeigt das Problem: Nachträglich geschriebene Tests passen sich dem falschen Code an, und Rückfragen stellt das Modell kaum. Weitere Themen: Feedback-Loops über Fehlermeldungen und Screenshots, Diagramme als Text für Mensch und Maschine, das Model Context Protocol mit Claude Desktop, Tutorials für Maschinen statt für Menschen, KI für COBOL-Altsysteme. Interessant für Entwickler:innen und Architekt:innen, die Agenten verstehen und ihnen verlässliche Prüfschleifen bauen wollen.
